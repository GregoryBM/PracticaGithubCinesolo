# Proyecto cine

Sitio web interactivo para la gestión y venta de entradas de cine, desplegado sobre un servidor web NGINX ejecutándose dentro de un contenedor Docker.

---

## Tecnología usada

* **Frontend:** HTML5, CSS3, JavaScript.
* **Servidor Web:** NGINX.
* **Contenedor:** Docker.

---

## Estructura del Proyecto

El proyecto se compone de los siguientes archivos:

```text
/
├── index.html           # Página principal (Venta de entradas)
├── ticket.html          # Vista/Confirmación del ticket
├── ventaentradas.css    # Estilos de la aplicación
├── ticket.css           # Estilos de los tickets
└── ventaEntradas.js     # Lógica interactiva en JS
